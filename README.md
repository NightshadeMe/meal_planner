# MealPlanner

A Python/KivyMD Android app for saving meals with ingredients and generating
interactive shopping lists. Meals can be shared between devices via QR code.

---

## Features

- **Meals** — create, edit, delete meals with named ingredients
- **Ingredient catalog** — shared ingredient table with locked units; autocomplete on entry
- **Shopping lists** — multiple named lists, generated by selecting meals; ingredients aggregated automatically
- **Interactive list** — quantity stepper (100-step for g/ml, 1-step for counts), purchased toggle, add custom items, clear purchased
- **QR sharing** — display a QR code for any meal; scan to import on another device with conflict resolution

## Development Setup (Desktop / Linux / macOS)

### 1. Prerequisites

- Python 3.11 or 3.12 recommended
- A virtual environment is strongly advised

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Install kivy-garden zbarcam

zbarcam is not on PyPI; install it via the kivy garden tool:

```bash
pip install kivy-garden
garden install zbarcam
```

On Linux you also need the native zbar library:

```bash
# Debian / Ubuntu
sudo apt install libzbar0

# macOS
brew install zbar
```

On Windows, `pyzbar` ships the DLL automatically — no extra step needed.

### 4. Run on desktop

```bash
cd meal_planner
python main.py
```

> **Note:** The Scan screen requires a real camera. On desktop without a
> webcam the screen will show a hint message and no camera preview.
> All other features work fully on desktop.

## Building the Android APK

### Prerequisites

Buildozer runs on **Linux only** (native or WSL2 on Windows).

#### System packages (Ubuntu / Debian)

```bash
sudo apt update && sudo apt install -y \
    git zip unzip openjdk-17-jdk \
    python3-pip python3-venv \
    libffi-dev libssl-dev libjpeg-dev \
    libzbar-dev zlib1g-dev \
    autoconf libtool pkg-config \
    cmake build-essential
```

#### Python tools

```bash
pip install buildozer cython==0.29.37
```

> Cython 0.29.x is required — Buildozer's python-for-android recipes do not
> yet support Cython 3.x.

#### Android SDK / NDK

Buildozer downloads the SDK and NDK automatically on first build.
Accept the Android SDK license when prompted:

```bash
yes | $HOME/.buildozer/android/platform/android-sdk/tools/bin/sdkmanager \
    --licenses
```

### Build

```bash
cd meal_planner
buildozer android debug
```

The first build takes 20–40 minutes (downloads SDK, NDK, and compiles all
recipes). Subsequent builds are much faster.

The APK is written to:

```
meal_planner/bin/mealplanner-1.0.0-arm64-v8a_armeabi-v7a-debug.apk
```

### Deploy to a connected device

```bash
buildozer android deploy run logcat
```

Ensure USB debugging is enabled on the device and `adb devices` shows it.

### Release build

1. Generate a signing keystore (once):

```bash
keytool -genkey -v -keystore mealplanner.keystore \
    -alias mealplanner -keyalg RSA -keysize 2048 -validity 10000
```

2. Add signing info to `buildozer.spec`:

```ini
android.keystore        = mealplanner.keystore
android.keystore_passwd = YOUR_PASSWORD
android.keyalias        = mealplanner
android.keyalias_passwd = YOUR_PASSWORD
```

3. Build:

```bash
buildozer android release
```

## QR Sharing — How It Works

**Sharing a meal:**

1. Open a meal → tap the QR icon in the top bar
2. A dialog displays the QR code — screenshot or show the screen to another device

**Importing a meal:**

1. Tap the **Scan** tab
2. Point the camera at the QR code
3. If the meal name already exists you will be prompted to:
   - **Overwrite** — replace the existing meal
   - **Save as copy** — saves with ` (copy)` appended to the name
   - **Cancel** — discard the scan

The QR payload is a compact JSON string (`< 500 bytes` for a typical meal)
well within the QR binary data limit of ~2,900 bytes.

## Unit Reference

| Unit   | Stepper step | Min value |
|--------|-------------|-----------|
| g      | 100         | 100       |
| ml     | 100         | 100       |
| pcs    | 1           | 1         |
| tsp    | 1           | 1         |
| tbsp   | 1           | 1         |
| cup    | 1           | 1         |
| pinch  | 1           | 1         |
| slice  | 1           | 1         |
| clove  | 1           | 1         |

Units are fixed per ingredient at creation time. The same ingredient always
carries the same unit across all meals, so shopping list aggregation is
always a clean sum — no unit conflict prompts needed.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError: peewee` | Run `pip install -r requirements.txt` |
| `ModuleNotFoundError: kivy_garden.zbarcam` | Run `garden install zbarcam` |
| Black screen on Android | Check `adb logcat` for Python traceback; most common cause is a missing `requirements` entry in `buildozer.spec` |
| Camera permission denied | Enable camera permission in Android Settings → Apps → MealPlanner |
| `Cython` build error | Downgrade to `pip install cython==0.29.37` |
| Long first build | Expected — Buildozer downloads ~1 GB of SDK/NDK on first run |
| QR not detected | Ensure good lighting; keep QR code flat and steady for 1–2 seconds |
